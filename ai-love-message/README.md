# 💌 AI Love Message Generator

Website romantis untuk membuat pesan manis menggunakan AI (Google Gemini).
Bisa dibagikan lewat link atau WhatsApp!

## ✨ Fitur

- 4 tema visual: Pink Love, Night Sky, Cute Sticker, Elegant Letter
- 7 mood pesan: Romantis, Lucu, Bucin, Minta Maaf, Semangat, Ulang Tahun, Kangen
- 5 tipe hubungan: Pasangan, Sahabat, Crush, Keluarga, Teman Dekat
- AI-powered (Google Gemini)
- Link shareable tanpa database
- Bagikan ke WhatsApp
- Auto-save ke localStorage
- Animasi hati melayang
- Responsive (mobile & desktop)
- Fallback otomatis jika AI error

## 📁 Struktur File

ai-love-message/

## 🚀 Deploy ke GitHub Pages

1. Push ke GitHub
2. Buka Settings → Pages
3. Source: branch `feature/nerslab-web`, folder `/ (root)`
4. Save
5. Akses: `https://USERNAME.github.io/Mencobadmaz/ai-love-message/`
